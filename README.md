# Setup instructions

### 1. Clone the Repository
```bash
git clone https://github.com/saramedhat258/desertCart.git
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run start
```

### 3. Run the JSON Server
```bash
json-server --watch db.json --port 8000
```

# ✨ Features

1) Add products to the cart
2) Increase and decrease quantity. When the quantity is less than 1, the product is removed from the cart
3) Remove products from the cart directly
4) See an order confirmation modal when clicking "Confirm Order"
5) Reset the cart when clicking "Start New Order"

# Technologies I used:
HTML, CSS, Bootstrap, React, Redux Toolkit, JSON Server
